MAGI is a personal assistant inspired by the iconic "Magi" computers from Evangelion. MAGI aims to be a user-centric tool that emphasizes privacy and local execution.

## 🎯 Vision

MAGI embodies the spirit of the Magi computers from Neon Genesis Evangelion, but with a modern focus on privacy, security, and user control. Unlike traditional AI assistants that rely heavily on cloud services, MAGI prioritizes local execution to ensure your data stays private and under your control.

## 🔒 Privacy First

- **Local Execution**: All processing happens on your device
- **No Data Collection**: Your personal information never leaves your machine
- **Open Source**: Full transparency in how the assistant works
- **Zero Tracking**: No analytics or user behavior tracking

## 🛠️ Getting Started

### Prerequisites

- Rust 1.56+
- Cargo (Rust package manager)

### Installation

```bash
git clone https://github.com/evan-trr/MAGI.git
cd magi
cargo build
```

### Usage

```bash
cargo run
```
